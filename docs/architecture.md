# 架构与维护入口

MP Inspector 由采集核心、事件总线和小程序组件组成。核心模块不依赖页面实例，记录可以跨页面保留；每个页面自行挂载面板，组件通过事件更新视图。

## 模块边界

| 路径 | 职责 |
| --- | --- |
| src/core/index.js | 配置、初始化、显示控制、销毁与模块编排 |
| src/core/console-interceptor.js | 包装 console，序列化日志，有界内存队列 |
| src/core/network-interceptor.js | 包装 wx.request，保留任务与回调，关联请求和响应 |
| src/core/error-handler.js | 在 App 注册时包装错误回调，继续调用业务处理器 |
| src/core/remote-logger.js | 可选的上报订阅、队列、发送与生命周期钩子 |
| src/core/event-bus.js | 核心与组件间的进程内事件 |
| src/core/storage-manager.js | 读取和删除小程序存储 |
| src/components/ | 悬浮按钮及 Console、Network、Storage 面板 |
| scripts/ | 构建、同步示例、打包 |
| tests/ | 模拟小程序宿主下的行为回归与构建契约 |

## 主要决策

**采集与显示分开。** init 决定安装哪些采集器，show/hide 决定面板是否可见。否则鉴权结果、页面切换或暂时收起面板容易改变正在采集的上下文。SDK 不提供业务鉴权。

**核心跨页面，组件管理订阅。** 单例事件总线让多个页面读取同一批记录；组件在 attached 订阅、detached 解绑。destroy 发出隐藏和清空事件，不移除其他调用方拥有的订阅，已挂载组件可以跟随重新初始化。

**包装 API 时保留调用契约。** request 使用浅拷贝选项替换回调，返回平台原始任务对象，继续传递响应和 this。请求 ID 不因清空而复用，实例代际阻止旧响应修改新实例。已注册 App 回调在销毁后继续执行业务逻辑，但不再采集。

**上报使用独立会话状态。** 每次安装对应一组队列、订阅和计时器。请求完成时核对会话，防止销毁后的延迟回调污染下一次初始化。上报请求使用保存的原始 request，防止自我采集。过滤钩子失败则丢弃数据。

**Full/Lite 共享源码。** 构建只在 Lite 中替换 remote-logger 为带 supported=false 的空模块；其余源码和组件相同。源码版本与 package.json 必须一致。两种压缩包均经过相同核心回归测试。

**示例由源码同步。** demo/lib 不入库。demo:sync 默认复制源码，也支持 full/lite 产物，避免修了源码却仍在验收旧示例。

## 当前限制

条数限制不等于字节限制。核心队列仍可能保留较大对象，界面通过 setData 更新也有开销；高频日志和大报文需要实际测量。远程日志仅在内存中保存，是尽力发送，不承担可靠消息队列的责任。包装全局 API 与其他工具的安装顺序有关；真机适配应进入回归清单。

后续改动优先从使用者反馈出发：问题能否复现、是否影响业务、发生在哪个基础库和系统版本。新增平台支持或可靠上报能力应单独设计与验证，避免在普通修复中改变边界。
